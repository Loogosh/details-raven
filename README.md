# Details! + RavenThreat for Raven

Package: stock **Details!** (plugins incl. TinyThreat) + **!RavenThreat** · Interface **11402**

## About

Upstream Details for RavenCraft 1.14.2, plus **!RavenThreat** CLEU threat feed for TinyThreat.

TinyThreat uses `Interface: 11402` (including `Details_TinyThreat-Classic.toc`) so it does not show **Out of date**.

## Status — not a final release

This is **not a finished, bug-free product**. Report problems via **Issue**.

## Install

Copy **all** folders from this package into `_classic_era_\Interface\AddOns` (keep the `!` in `!RavenThreat`), then `/reload`.
